# Short Video Studio 首页设计提示词

```text
你是一名资深 AI 产品设计师与前端设计工程师。请在现有项目中设计并实现一个新的“创作首页”，将 Short Video Studio 从默认直接进入单一视频面板，升级为一个由 Agent 驱动、可以继续进入专业工作台的 AI 媒体创作入口。

参考“小云雀 AI”首页的产品设计思想：一句话开始创作、用户目标优先、视觉内容优先、隐藏不必要的模型复杂度、从灵感自然进入生成流程。只参考信息架构、视觉层级和交互逻辑，不复制其 Logo、品牌名称、图片、图标、文案、布局细节或其他视觉资产。

这不是重新制作一个营销官网，也不是把现有应用替换成聊天机器人。首屏必须是可以实际操作的创作工作台。

## 一、先理解当前项目

项目名称：`Short Video Studio`

这是一个面向作品集展示、同时接入真实生成服务的 AI 图片与短视频创作平台。当前使用 React、Vite、原生 CSS 和 `lucide-react`，没有前端路由库，主入口通过 `src/main.jsx` 中的本地 `studio` 状态切换页面。

现有四个真实模块：

1. `视频创作`：支持文生视频、首帧驱动、首尾帧、多关键帧、多图参考、视频续写、视频编辑、动作迁移和角色替换等工作流，具体能力由服务端当前返回的兼容模型决定。
2. `图片创作`：支持文生图和参考图编辑，可上传多张图片，结果可以保存到资产库或继续交给 Agent。
3. `创作 Agent`：不是通用聊天机器人。它根据用户输入制定图片或视频计划，展示目标媒体、工作流、模型、服务商和输出规格，用户确认计划后才调用真实生成服务。
4. `创作资产`：按项目、类型和标签管理图片、视频、文档等资产，保留模型、提示词、参数、版本和资产关系。数据当前保存在浏览器 `localStorage`。

现有 Agent 的真实项目流程为：

`创作立项 -> 分镜资料 -> 镜头审核 -> 生成素材 -> 资产沉淀`

项目可从灵感或剧本开始，按约 5 秒拆分镜头；每次真实调用只执行当前审核过的镜头。当前 Agent 主要负责图片/视频模型选择与任务编排，不要把它描述成已经能够自动完成配音、BGM、字幕、剪辑或完整长片合成。

系统会受到真实模型可用性、免费模型保护、额度耗尽、排队、生成失败和上游服务错误影响。页面必须忠实表现这些状态，不能用虚假的生成结果或固定成功流程掩盖真实服务。

## 二、设计目标

让第一次打开应用的用户在 10 秒内理解：

- 这里可以用一句话创建图片或短视频。
- Agent 会先规划，再由用户确认并执行，不会未经确认直接消耗生成额度。
- 用户也可以进入图片或视频专业工作台，手动选择工作流、模型和素材。
- 已创建的项目、未完成镜头和生成结果会沉淀到资产库。

首页的核心感受应当是：

> 先说出想法，再决定由 Agent 自动规划，还是进入专业工作台精细控制。

首页要解决“从哪里开始”和“如何继续”，而不是在首屏展示大量模型参数。

## 三、明确的设计方向

视觉方向采用小云雀同类的浅色 AI 创作工具配色：雾白背景、纯白表面、低饱和薰衣草紫作为唯一主强调色。保留当前项目的专业控制台信息密度，不复制参考网站的 Logo、图片、图标或具体视觉资产。

整体气质：轻量、克制、清晰、可执行。参考产品的轻盈感通过柔和明度层级、稳定网格和清晰焦点实现，不使用玻璃拟态、彩色背景球、夸张渐变或大圆角卡片。

使用现有核心色彩：

- 页面背景：`#F7F7FB`
- 基础表面：`#FFFFFF`
- 抬升表面：`#FAF9FF`
- 激活表面：`#F0EEFF`
- 普通边框：`#E7E7F0`
- 强边框：`#D5D4E5`
- 主要文字：`#24232D`
- 次要文字：`#777484`
- 唯一品牌信号色：薰衣草紫 `#695BFF`
- 警告：`#D77A22`
- 错误：`#DF4D58`

不要新增彩色背景装饰。不要让紫色大面积铺满页面；它只用于当前导航、主操作、活动节点、键盘焦点和关键状态。

排版继续使用项目已有的字体体系。标题保持工具感，不使用营销页的超大字体。字间距为 0。

圆角保持 0-6px，以边框和明度差建立层级。不要使用 20px 以上大圆角，不要卡片嵌套卡片，不要使用柔和大阴影。

本次设计的记忆点是：用户输入一句创作描述后，输入区下方立即展开一条真实的“创作路径带”，将 `输入 -> Agent 计划 -> 用户确认 -> 图片/视频任务 -> 资产归档` 可视化；路径节点会根据真实状态逐步点亮，并允许用户点击回到对应模块。

## 四、应用信息架构

新增一个 `首页` 入口，并将它设为应用默认入口。顶部导航统一为：

`首页 / Agent / 视频 / 图片 / 资产`

建议新增 `HomeStudio` 组件，而不是把首页内容全部塞进 `App` 或现有 `VideoStudio`。继续沿用当前的本地状态切换方式，不要为了一个首页引入路由框架。

建议组件拆分：

- `HomeStudio`
- `HomeTopbar`
- `CreationCommand`
- `CreationRoutePreview`
- `CreationEntrances`
- `ActiveProjects`
- `RecentAssets`
- `WorkflowOverview`
- `InspirationPrompts`

首页只负责分发、恢复和概览。视频、图片、Agent、资产模块继续保留各自专业界面，不要把所有复杂设置搬到首页。

## 五、顶部导航

顶部使用固定、紧凑的应用导航，高度约 72-82px，与现有工作台保持同一产品外壳。

左侧：

- `SHORT VIDEO STUDIO`
- 当前页面标题 `创作首页`

中间：

- 首页
- Agent
- 视频
- 图片
- 资产

当前入口使用酸橙绿实底或清晰的活动状态。导航使用 Lucide 图标加简短文字，移动端可以缩短为图标和必要标签，但必须保留可访问名称和 Tooltip。

右侧只显示真实信息：

- 刷新模型状态
- 当前可用模型数量
- 暂停或不可用模型数量
- 当前本地项目数量

不要添加项目尚不存在的登录、积分、会员、通知或云同步入口。

## 六、首屏创作命令区

首屏不使用传统 Hero，不写“欢迎来到”或冗长宣传文案。标题控制在两行内：

主标题：`从一个想法，开始一段创作。`

支持文案：`让 Agent 规划图片或视频路径，也可以进入专业工作台精细控制。`

标题下方放置首页视觉核心：一个宽度约 760-920px、最小高度约 150px 的创作命令区。它不是聊天气泡，而是一个明确的任务输入控制台。

输入内容：

- 多行创作描述，最多 5000 字。
- 来源切换：`灵感` / `剧本`。
- 目标切换：`自动判断` / `生成图片` / `生成视频`。
- 视觉风格：`2D 动漫` / `电影感` / `写实质感` / `产品展示`。
- 视频目标下显示比例和项目时长；图片目标下隐藏不相关的视频参数。

主操作：`制定创作计划`

次操作：

- `进入视频工作台`
- `进入图片工作台`

首页点击主操作后应把输入带入现有 Agent 页面，并继续现有“制定计划 -> 审核 -> 确认执行”的真实流程。不要在首页复制第二套 Agent 请求、任务轮询或结果状态。

输入为空时主按钮不可提交，并在按钮附近提示“请先描述想创作的内容”。输入获得焦点时只使用绿色细边和轻微表面变化，不使用发光渐变。

可以提供 3-5 个明确标为“示例”的 prompt 快捷项。点击后只填充输入框，不立即生成。例如：

- `制作一段 15 秒竖屏咖啡新品短片，暖色晨光，镜头从杯沿推进。`
- `把一张商品图改造成黑色背景的高对比广告海报。`
- `根据这段剧情建立 30 秒短片项目，并拆分为连续镜头。`

示例是输入范例，不得伪装成用户的历史内容或真实热门数据。

## 七、创作路径预览

命令区下方显示一条紧凑、可解释的路径带。未输入时显示：

`创作描述 -> Agent 规划 -> 审核计划 -> 真实生成 -> 资产归档`

输入或切换目标后，根据当前选择更新为更具体的预览，例如：

`剧本 -> 自动判断 -> 镜头审核 -> 图片或视频 -> 当前项目`

这里不提前显示虚构模型名。只有服务端返回 Agent 计划后，才可以展示真实模型、服务商和输出规格。

状态语义：

- 未开始：灰色节点
- 当前步骤：酸橙绿节点与边框
- 已完成：白色文字加完成图标
- 警告：琥珀色并附明确文案
- 失败：红色并保留重试或返回调整入口

动画仅用于节点状态切换，时长 150-220ms。禁止循环扫描线、粒子、夸张发光或自动播放的装饰动画。

## 八、创作入口

路径带下方设置四个清晰入口，但不要做成营销功能卡片：

1. `让 Agent 规划`：从一句灵感或剧本建立项目，审核后执行。
2. `精细生成视频`：进入现有视频工作台，选择真实工作流、模型和素材。
3. `生成或编辑图片`：进入现有图片工作台，支持文生图与参考图编辑。
4. `管理创作资产`：查看项目、版本、提示词、模型参数与关联素材。

入口采用一条横向分区或两列稳定网格。每个入口使用真实功能名称、Lucide 图标和一句操作说明。hover 只改变背景、边框或上移 2px，不放虚构缩略图，不显示“爆款”“热门”等营销标签。

## 九、继续创作

如果 `library.projects` 中存在项目，首页展示 `继续创作` 区域，按更新时间优先显示真实项目。

每个项目需要呈现：

- 项目标题
- 项目状态：`planned` / `in_progress` / `complete` 对应的中文状态
- 视觉风格、比例和项目时长
- 已完成镜头数 / 总镜头数
- 最近更新时间
- `继续项目` 操作
- `查看资产` 操作

点击继续项目后进入 Agent，并选中对应项目或至少进入可继续该项目的上下文。不要将项目渲染成传统表格，也不要伪造项目封面。若项目已有真实图片或视频资产，可以用当前版本资产作为预览；否则使用结构化文字状态和镜头进度。

如果没有项目，显示诚实的空状态：`还没有创作项目`，并提供 `从一句想法开始`。不要生成假项目填满页面。

## 十、最近资产

从 `library.assets` 中读取真实资产，展示最近更新的图片、视频和文档。

- 图片使用真实 `previewUrl`。
- 视频使用真实媒体预览或静态首帧能力；如果无法安全取帧，使用视频类型占位，不伪造封面。
- 文档使用标题、类型和内容摘要。
- 显示资产类型、版本、所属项目和更新时间。
- 提供 `打开资产库` 和单项查看操作。

可以使用项目内 `public/examples` 的素材作为“内置示例”，但必须明确标注为示例，不能与用户生成资产混为一谈。优先级始终是：用户真实资产 > 明确标注的项目示例 > 空状态。

布局使用内容优先的 Bento 式网格，但保持工业风的直角边界和 1px 分隔线。允许一项真实视频或图片占据更大区域，其余资产使用稳定的小网格；不要为了 Bento 效果制造不一致或内容裁切。

## 十一、真实能力概览

设置一个紧凑的 `专业工作流` 区域，让用户理解进入视频或图片工作台后能做什么。

只展示项目真实支持的能力：

- 视频：文字创作、图片驱动、参考一致性、视频再创作。
- 图片：文生图、参考图编辑。
- Agent：自动判断图片/视频路径、审核计划、当前镜头执行、资产回写。
- 资产：项目归档、版本、提示词、参数和关系追踪。

能力是否可用应以 `/api/models` 和现有兼容性函数为准。当前没有兼容模型时要显示“暂不可用”，不能仍然把入口表现为可执行。

不要展示尚未接入的数字人、AI 音乐、自动配音、自动字幕或完整视频剪辑为已完成能力。若需要出现，只能放在明确的“待接入”说明中，且不作为主要首页内容。

## 十二、创作方式而非模型品牌

首页不直接排列模型 A、模型 B、服务商 C。用用户目标组织入口：

- `电影感短片`
- `竖屏社交视频`
- `商品广告画面`
- `2D 动漫内容`

这些方式可以映射到当前 Agent 的视觉风格、比例和目标类型，点击后填充首页控件。真实模型仍由 Agent 计划或专业工作台选择。

任何模型名称、变体、免费状态、服务商和规格只能来自当前真实目录，不能写死新的模型能力。

## 十三、交互与真实状态

必须覆盖：

- 默认
- Hover
- Active
- Focus
- Disabled
- Loading
- Empty
- 模型目录加载失败
- 无可用模型
- 额度暂停
- Agent 计划中
- 计划待确认
- 任务排队
- 生成中
- 完成
- 失败
- 本地项目或资产数据损坏后的安全空状态

不要承诺精确剩余时间。不要使用假进度模拟成功。防止重复提交。任务进行时允许用户切换模块后返回，并继续使用项目已有的任务恢复机制。

标准操作使用标准文案，不要用故作神秘的科幻词汇替代“制定计划”“开始生成”“重新提交”“查看资产”等明确命令。

## 十四、响应式

桌面端：

- 适配 1440px 和 1920px。
- 首屏命令区是主焦点，但不要占满整个视口。
- `继续创作` 与 `最近资产` 可使用两栏或 Bento 网格。

平板端：

- 适配 768px。
- 顶部导航允许横向滚动。
- 命令区参数改为两列。
- 项目与资产变为单列或两列稳定网格。

移动端：

- 适配 375px、390px、430px。
- 页面顺序为：顶部导航 -> 标题 -> 创作命令 -> 主操作 -> 路径带 -> 创作入口 -> 继续创作 -> 最近资产。
- 来源、目标和风格控件允许横向滚动或换行，不得压缩文字。
- 输入区、按钮、项目进度和长错误文案不得重叠。
- 主按钮保持可见、可点击，不能被固定导航或浏览器安全区遮挡。

## 十五、实现边界

先阅读并复用：

- `src/main.jsx`
- `src/agent-studio.jsx`
- `src/image-studio.jsx`
- `src/assets-studio.jsx`
- `src/styles.css`
- `src/creative-library.mjs`
- `src/task-session.mjs`
- `shared/creative-agent.mjs`
- `shared/video-models.mjs`
- `shared/image-models.mjs`
- `shared/free-models.mjs`

不要重写整个项目。不要改变现有 API 协议、免费模型保护、服务端密钥边界、任务轮询协议或资产数据结构。

优先实现方式：

1. 新增独立 `HomeStudio` 及必要的首页子组件。
2. 在 `App` 中新增 `home` 状态并设为默认值。
3. 将现有 `library.projects`、`library.assets` 和各工作台切换回调传入首页。
4. 首页主输入生成一个 `launchDraft`，复用现有 Agent 页面继续计划流程。
5. 抽取统一顶栏时要小步进行，避免一次性重构四个成熟工作台。
6. 只在确有必要时扩展项目选择或恢复上下文，不复制任务请求与轮询逻辑。

不要引入新的 UI 框架。继续使用 `lucide-react`。不要手绘 SVG 图标，不要用 Unicode 字符代替图标。

## 十六、验收标准

最终交付必须满足：

1. 应用默认进入新的创作首页，且可以正常切换首页、Agent、视频、图片和资产。
2. 首页输入可以真实带入 Agent，而不是只有视觉效果。
3. 首页项目和资产来自 `localStorage` 中的真实数据；没有数据时显示空状态。
4. 页面不虚构模型、任务、项目、用户、积分、生成结果或未接入能力。
5. 保持雾白底、低饱和薰衣草紫信号色和克制网格，不漂移成高饱和通用 AI SaaS。
6. 桌面、平板和手机布局均无文字溢出、控件重叠或横向页面滚动。
7. 键盘焦点、Tooltip、可访问名称和 `prefers-reduced-motion` 完整。
8. `npm test` 与 `npm run build` 通过。
9. 使用浏览器在 1440px、768px、390px 视口验证首屏、空状态、存在项目/资产状态和 Agent 跳转。
10. 最终说明修改的组件、数据来源、真实状态处理和验证结果。

最终效果不应只是“像小云雀”，而应当让人明确感受到：

> 这是 Short Video Studio 自己的创作首页。它让新用户可以一句话开始，也让熟练用户随时进入真实、可控、可追溯的专业工作流。
```

## 使用说明

将上方代码块作为前端实现任务的主提示词。若只修改首页，在末尾补充“本次仅实现首页与必要的数据传递，不重构视频、图片、Agent、资产四个工作台内部布局”。
